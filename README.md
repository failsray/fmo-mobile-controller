# FMO-X Mobile Controller

FMO-X 是专为移动端设计的 FMO 远程控制器，用于远程控制 FMO 并实时收听 / 可视化音频流。当前版本 **1.6.6**。

> FMO 仅服务于持有业余无线电执照的爱好者。

## 📱 当前版本：1.6.6

*   应用名：**FMO-X**（桌面名、安装名）
*   包名：`com.x.fmocontroller`
*   版本：**1.6.6**（versionCode 3）
*   全面屏：状态栏 / 导航栏透明，刘海屏适配，内容延伸到屏幕边缘，网页层安全区避让；日间、夜间模式均已适配。

## ✨ 主要功能

*   **实时音频流**：基于 Web Audio API 和 WebSocket 接收 PCM 音频流（16 位、8kHz、单声道），低延迟播放。
*   **炫酷可视化**：内置高性能 Canvas 音频可视化引擎，支持 7 种模式，点击可视化区域循环切换，默认为 **RADIAL（径向频谱）**：
    *   Spectrum（频谱图）
    *   Mirror（镜像频谱）
    *   Waveform（波形图）
    *   Oscilloscope（示波器）
    *   Radial（径向频谱，默认）
    *   Particles（粒子效果）
    *   Solar（太阳系）
*   **太阳系（Solar）**：太阳居中并标注 Sun，行星沿轨道环绕；有人讲话时呼号字幕显示在可视化区底部（离底边 45px，台站名上面一行），各模式位置一致，不遮挡台站名，呼号只出现一次。
*   **多主题支持**：内置 5 套主题，支持一键切换（默认为橙色暗黑风格）。
*   **远程控制**：
    *   服务器连接管理（支持历史记录、自动重连）。
    *   台站切换与列表自动刷新（每 30 秒刷新，每页 20 条）。
    *   音量控制（触摸优化滑块）。
    *   录音功能（支持导出 WAV）。
*   **QSO 日志查看**：内置弹窗查看服务器端的通联日志记录。

## 🚀 快速开始

1.  **安装应用**：安装 `FMO-X-1.6.6.apk`。同一版本覆盖安装即可，设置和 IP 都在；从 1.6.2（包名 `com.example.fmocontroller`）升级需先卸载旧版再装，设置和 IP 需重填。
2.  **连接服务器**：
    *   点击右上角的 **设置图标**（⚙️）展开设置面板。
    *   在输入框中输入 FMO 服务器的地址（IP 或域名，例如 `192.168.110.198`）。
    *   点击 **CONNECT** 按钮，页面 1 秒后也会自动连接上次保存的地址。
3.  **开始使用**：连接成功后，状态指示灯将变绿，您可以开始播放音频、切换台站或查看可视化效果。

## 📱 界面指南

### 顶部导航栏
*   **Logo**：显示应用名称。
*   **功能按钮**：
    *   📝 **QSO 日志**：点击查看服务器记录的通联日志。
    *   ⚙️ **设置**：展开 / 收起连接设置面板。
    *   🎨 **主题**：循环切换界面主题风格。
*   **状态指示灯**：
    *   左侧圆点：控制信令（WebSocket）连接状态。
    *   右侧圆点：音频流（Audio）连接状态。

### 可视化区域
*   点击可视化画布区域可循环切换 **7 种显示模式**。
*   右上角标签显示当前模式名称。
*   有人讲话时，当前讲话人的呼号显示在可视化区底部居中，各模式位置一致。

### 控制面板
*   **播放 / 暂停**：控制音频流的连接与断开。
*   **录音**：点击开始录制当前音频，再次点击停止并下载 WAV 文件。
*   **音量**：拖动滑块或点击图标静音。
*   **台站列表**：显示当前可用台站，支持点击切换。列表每 30 秒自动刷新。

## 🛠 技术说明

*   与 FMO 设备之间通过 3 条 WebSocket 连接：
    *   `/ws`：台站切换 / 列表。
    *   `/audio`：PCM 16 位、8kHz、单声道音频流。
    *   `/events`：当前呼号字幕推送。
*   控制连接断线后 3 秒自动重连；台站列表每 30 秒自动刷新。
*   网页控制端为单文件 HTML（`fmo-mobile-controller.html`），也可以直接在浏览器中打开使用；打开为 https 时自动使用 `wss://`，http 时使用 `ws://`。

## 📋 浏览器兼容性

需要支持以下特性的现代浏览器：
*   WebSocket API
*   Web Audio API
*   ES6 Classes & Modules

推荐使用 Chrome（Android / Desktop）或 Safari（iOS）。
